# Notes

This folder holds text transcriptions of the study's planning documents, kept
**locally only** and excluded from the public repository (`.gitignore`):

| File | What it is |
|---|---|
| `proposal.md` | The study proposal: motivation, research questions, sweep axes |
| `methods_supplement.md` | The full planned method, with comments raised in review |
| `bhaskar_FYR.md` | A colleague's first year report documenting the connectome pipeline that produced the data (unpublished) |

The public record of what was planned and what was decided lives in the project
root: `ANALYSIS_PLAN.md` (the plan as executed), `DECISIONS.md` (every choice
and why, including where the data overrode the plan) and `SUPPLEMENT.md` (the
evidence behind each choice). References there to points "raised in review"
refer to review comments on the methods supplement.
