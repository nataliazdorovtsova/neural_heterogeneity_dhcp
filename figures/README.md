# Figures

Every figure is regenerated by a script in `scripts/` (named in
SUPPLEMENT.md) and saved as PNG and PDF in the style of `figstyle.py`.

**Status, 2026-11-04: interim.** The figures in this folder come from the
original run, in which clustering was normalised by each infant's strongest
connection. That normalisation produced an artefactual axis (DECISIONS.md D17),
so:

- in `fig3_axes_overview`, `fig4_axis_maps`, `fig5_axis*_brain`,
  `fig6_region_profiles`, `fig8_axis_significance` and `fig9_tail_structure`,
  **axis 1 is withdrawn**. Axes 2 and 3 are robust (SUPPLEMENT S32);
- the clustering curves in `fig15_trajectories` and `fig16_trajectory_maps`
  use the old clustering definition;
- `fig11`–`fig14` are sensitivity checks against the original run and stay
  as they are.

The rerun with one clustering normaliser for every infant (D18) writes its
figures to `figures/d18/`, which will replace these as the main figures.
